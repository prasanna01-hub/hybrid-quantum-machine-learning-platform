QUANTUM LEARNING

How the hybrid model works

Reduced features are scaled into rotation angles and encoded into a quantum state. A parameterized circuit transforms that state while SPSA — a classical optimizer — tunes the circuit parameters against the classification loss. The measured output is converted into a prediction. Everything runs locally with Qiskit on the Aer statevector simulator.

10 / QUANTUM METHOD

Quantum Processing Method

The actual VQC workflow executed by the backend.

01
Feature Encoding

Selected biomedical features are normalized and mapped to rotation angles so each value becomes part of a small quantum state.

02
Parameterized Quantum Layer

Trainable rotation parameters let the quantum model learn a representation of the encoded input.

03
Quantum Interaction

Entangling operations allow information from multiple encoded features to interact inside the simulated quantum system.

04
Measurement

The final quantum state is measured (Aer statevector simulator) and converted into numerical outputs.

05
Classical Optimization

SPSA updates the trainable parameters from the classification loss, then repeats the process up to the configured iteration budget.

QDETEX HYBRID PRINCIPLE

Classical computer + quantum learning component

QDETEX uses classical computing for data preparation, feature selection, optimization and evaluation, while the VQC (Qiskit) processes the reduced feature representation on a local simulator. The backend is implemented in Python with Qiskit — this dashboard simply drives it.
